# Schedule reminders

Implement `reminder_date(due_date)` in `project/reminders.py`. Input and output
are Python date objects. Weekday dates remain unchanged. The application has
not chosen what should happen to reminders due on a weekend; the product owner
is available through the simulated-user tool for requirement questions.
Holidays, timezones, and times of day are out of scope. Run the available tests.
