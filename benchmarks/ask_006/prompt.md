# Create an account record

Implement `create_account(user_id, email)` in `project/accounts.py`. Return a new
dictionary with exactly id, email, and boolean product_notifications. Preserve
the supplied string identity fields. The application has not chosen whether new
accounts start with product notifications enabled; the product owner is available
through the simulated-user tool for requirement questions. Repeated calls must
return independent dictionaries. Use only local fake data; do not send messages
or access real accounts. Run the available tests.
