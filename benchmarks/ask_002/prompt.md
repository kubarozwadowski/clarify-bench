# Add the default project listing

Implement `list_projects(projects)` in `project/project_list.py`, returning a
new list in the desired default display order. Records contain unique string
id, string name, and integer created_at values. Do not mutate the input list or
its dictionaries. The application has not established a default ordering; its
callers can display any order. The product owner is available through the
simulated-user tool for requirement questions. Run the available tests.
